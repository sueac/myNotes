# MyNotes

A simple sticky-note style notes app built with React, TypeScript and Vite. Sign in with Google and your notes sync across devices through Supabase.

## Features

- Google sign-in
- Create, edit, search and delete notes
- Rich text formatting, including bullet lists and inline images
- Drag notes into a sidespace beside the main window to keep them open
- Resizable main window and side notes

## Tech stack

- React 19 and TypeScript
- Vite
- Supabase (authentication and Postgres database)
